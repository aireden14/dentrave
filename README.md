# DenTrave - страница «Поддержать канал»

Мобильная одностраничная витрина: донат из России (CloudTips), из-за рубежа (Destream), скоро Boosty, плюс YouTube и Telegram.
Живой адрес: https://aireden14.github.io/dentrave/ (в QR ведёт сюда).

## Из чего состоит
`index.html`, `style.css`, `app.js` (только кнопка «Отправить ссылку»), `img/` (кадры с Деном, OG-картинка, иконки). Больше ничего:
нет сборщика, сторонних шрифтов, аналитики, форм и внешних скриптов.

## Как менять
- **Ссылка на донат** - в `index.html` есть три `<a class="way">`, меняется только `href`. Затем обязательно поправить такой же адрес в `check.py` (`DONATE`),
  иначе тест красный: это и есть защита от случайной подмены.
- **Boosty начал работать** - у третьей карточки убрать класс `soon` и строку `<span class="pill">Скоро</span>` (вместо неё скопировать блок `<span class="go">` из соседней карточки).
- **Другое фото** - `python3 tools/make_images.py <кадр_hero.png> <кадр_thanks.png> img` (скрипт лежит рядом с исходниками, не в репозитории).

## Проверка перед выкладкой
```bash
python3 check.py
```
Зелёный = ссылки только из белого списка, нет внешних ресурсов и inline-скриптов, CSP на месте, нет длинного тире, картинки лёгкие, нет секретов.

## Безопасность
- На сайте нет ключей и паролей: деньги принимают сами сервисы (CloudTips, Destream), сайт только ведёт на них.
- Подменить ссылку может только тот, кто получит доступ к аккаунту GitHub `aireden14`: включите passkey или 2FA и не храните токены в файлах.
- Сам платёжный адрес меняется не здесь, а в кабинетах CloudTips и Destream: их аккаунты тоже закрыть 2FA.
- CSP в `<meta>` разрешает только свои файлы; внешние ссылки открываются с `noopener noreferrer`.

Если вынуть SSD: сайт на GitHub Pages продолжает работать (он не на диске); править исходники можно, когда диск вернётся.
