# DenTrave - страница «Поддержать канал»

Одностраничная витрина: донат из России (CloudTips, главная красная кнопка), из-за рубежа (Destream), Boosty, крипта (вкладки сетей), плюс YouTube, Telegram и Twitch.
Внизу блок «Спасибо вам»: имена поддержавших плывут вверх, как огоньки. На компьютере и телевизоре фото Дена слева липкое, контент справа (как в роликах).
Живой адрес: https://dentrave.com/ (с 08.11.2026; прежний aireden14.github.io/dentrave/ перенаправляет сюда; в QR - новый адрес).

## Из чего состоит
`index.html`, `style.css`, `app.js` (кнопка «Отправить ссылку», «Копировать», вкладки сетей, плавающие имена), `img/` (кадры с Деном, OG-картинка, иконки). Больше ничего:
нет сборщика, сторонних шрифтов, аналитики, форм и внешних скриптов. Размеры в rem, поэтому та же вёрстка держится от телефона до 4K.

## Как менять
- **Имена в «Спасибо вам»** - список `<ul class="donors">` в `index.html`, по одному `<li>` на человека. Только имя, как человек сам его оставил (без сумм, телефонов, ников Телеграма:
  `check.py` такое не пропустит). Число «и ещё N человек» (без имени) - строка `donors-more` под списком. Источник имён: `МОНТАЖ ВИДЕО/_СЛУЖЕБНОЕ/КОММЕНТАРИИ ДЛЯ МОНТАЖА (в будущие ролики)/ДОНАТЕРЫ/донатеры.json`;
  у Boosty показаны имя и первая буква фамилии. Убрать человека по его просьбе - удалить его `<li>`. Скорость, разброс и число огоньков - в блоке «4.» файла `app.js`.
  Без скрипта и при «уменьшить движение» имена остаются спокойным облаком.
- **Ссылка на донат** - в `index.html` есть три `<a class="way">`, меняется только `href`. Затем обязательно поправить такой же адрес в `check.py` (`DONATE`),
  иначе тест красный: это и есть защита от случайной подмены.
- **Другое фото** - `python3 tools/make_images.py <кадр_hero.png> <кадр_thanks.png> img` (скрипт лежит рядом с исходниками, не в репозитории).

## Проверка перед выкладкой
```bash
python3 check.py
```
Зелёный = ссылки только из белого списка, нет внешних ресурсов и inline-скриптов, CSP на месте, нет длинного тире, картинки лёгкие, нет секретов.

## Безопасность
- На сайте нет ключей и паролей: деньги принимают сами сервисы (CloudTips, Destream), сайт только ведёт на них.
- Подменить ссылку может только тот, кто получит доступ к аккаунту GitHub `aireden14`: включите passkey или 2FA и не храните токены в файлах.
- Сам платёжный адрес меняется не здесь, а в кабинетах CloudTips и Destream: их аккаунты тоже закрыть 2FA.
- CSP в `<meta>` разрешает только свои файлы; внешние ссылки открываются с `noopener noreferrer`.

Если вынуть SSD: сайт на GitHub Pages продолжает работать (он не на диске); править исходники можно, когда диск вернётся.
